# DENTEX INDUSTRIES LTD

Project Overview
Build a premium, fully responsive multi-page corporate website for Dentex Industries Ltd, a Kenyan rigid plastic packaging manufacturer established in 1986 serving pharmaceutical, food & beverage, and industrial sectors.

Pages Required: Home, About Us, Our Products, Quality & Innovation, Contact Us. All pages should share a consistent navigation header and footer.

Tech Stack & Styling
Framework: React with TypeScript

Styling: Tailwind CSS

Animations: Framer Motion for all page transitions, scroll animations, and interactive elements

Icons: Lucide React icons

Font: Inter (Google Fonts)

Color Palette:

Primary: Deep corporate blue #0A2540

Secondary: Clean white #FFFFFF and technical grey #F4F4F4

Accent: Vibrant green #00A651 (representing growth and sustainability)

Text: Dark grey #1A1A1A for body copy

Design Aesthetic: Industrial, reliable, innovative, and professional. Clean typography, generous whitespace, subtle shadows, and rounded corners.

Global Elements (All Pages)
Sticky Header: Logo (placeholder: "Dentex Industries Ltd" in bold), navigation links (Home, About Us, Our Products, Quality & Innovation, Contact Us), and a prominent "Get a Quote" CTA button in the accent green color.

Footer: Company name, address (Dentex House, Athi River Road, Nairobi), contact details, quick links, social media icons (LinkedIn, etc.), and copyright notice.

Interactive Elements: Smooth scroll behavior, hover animations on all buttons and cards, and subtle fade-in animations as sections come into view.
